Quarterly report user guide

For each quarter, complete Evidence and sources with the source, reporting period, method, numerator and denominator where relevant, sample size and limits. This context appears in every report view and in saved report files. When an older file has no evidence entry, add it before interpreting or sharing the results.

The Equity and Inclusion Operations Consultant leads One DSD People, Access and Culture. This document supports planning and review; proposed assignments, measures, resources and schedules must be confirmed with the people responsible. It does not create new DHS policy or replace required decision authority.

How to use it

Disability Services Division (DSD) · One DSD People, Access and Culture

What it is

The consultant leads program reporting, drawing on updates from the people responsible for each goal and area of work. The Equity and Inclusion Operations Consultant supports them by advising, coaching and connecting people, and helps put the report together. The Equity and Inclusion Operations Consultant leads the program and coordinates reporting. Each contributor remains responsible for the work and information they provide.

The quarterly report is one file, One_DSD_Quarterly_Report_Dashboard.html. Double-click it and it opens in your web browser. You do not need the internet or a login. It automatically saves in this browser on this device. Download a report to keep a separate copy or share an approved summary. No report is sent to the program server.

The report starts empty so practice numbers cannot be mistaken for actual results. Choose View examples to explore a separate practice report, and Return to real report when ready. Examples cannot be relabeled as real or overwrite a real browser save. Enter verified aggregate numbers in the real report and leave unavailable values blank.

The four pages

Use the buttons under the title to switch pages. These views do not enforce access permissions. Share only the reviewed view or summary appropriate for the audience; a full report file contains every view. Recover previous save can restore the previous browser copy after a mistaken change.

Every quarter, step by step

Open the report file. Click Open saved report and choose last quarter's saved file (one-dsd-quarterly-report.json).

Click Add a quarter. A form opens with the quarter's name already filled in.

Each person fills in their own part. Each goal lead fills in their goal's status, this quarter and next quarter. The upkeep, support and data contacts fill in their sections and their numbers. Leaders fill in the summary, the owners section and the checkpoint items that are done. The consultant fills in the coaching and support given and the support planned. If a number is not available yet, leave it blank. It will show as a dash, not a zero.

The One DSD Team fills in its own section.

The consultant leads preparation of the report with input from the people responsible for each area. Contributors check the accuracy of their own information.

Click Done, then Save report. The file goes to your Downloads folder. Move it to the team's shared folder.

Click Print this view to print the selected page, or choose Save as PDF in the print window. Review the audience and content before sharing each view.

Send the report to DSD leaders. Leaders read the "For leaders" page, make the decisions listed, and sign off.

Share the Team page and the "you said, we did" summary with all staff. Send the leaders' page to the ADSA Equity Director with the DSD status report.

To look at an earlier quarter, choose it from the list at the top. To fix something, choose the quarter and click Add or change this quarter's numbers.

Warning signs

The report checks for warning signs every quarter. If one appears, it shows in red on the leaders' page with who should act. A warning means leaders should look into it now, not wait for the next report.

The starting warning levels support discussion; they are not policy requirements. Review thresholds with the consultant and appropriate data owners before using them to interpret results. Changing a threshold affects this report file. Retain an earlier export when documenting a change.

The numbers

The report carries the 21 headline numbers from the One DSD Data and Metrics Framework:

Program health (6): units with a decision record, plan or review; outcome records shared about what changed; decisions changed by a review; help requests finished; time to first reply; pages current and accessible.

Each of the six ADSA goals (2 each): shown beside each goal on the leaders' page.

Leadership (1): goals and areas with a named owner.

Workplace culture (2): belonging and trust score, and the gap between groups.

All of them are totals for the division, and none counts learning or use of the program: no page views, completions or attendance. Some numbers, like the gap between groups in who stays, come from more detailed tables; put the one summary number here and keep the detailed table with the written report. The full set of measures is in the framework and is reviewed once a year. If a number is not available yet, leave it blank. In Year 1 many numbers will be blank; that is expected.

Privacy

Never put names, case details, personnel details or any one person's results in the report. Describe people by role, unit or community. The program keeps no personnel records, and this report must not become one.
