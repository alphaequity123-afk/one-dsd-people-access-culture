One DSD People, Access and Culture

HCBS equity policy analysis user guide

These guides support independent use by DHS staff, with optional help from the Equity and Inclusion Operations Consultant. The consultant leads One DSD People, Access and Culture. Tool drafts are saved in the current browser on this device and can be downloaded or imported; they are not sent to the program server.

User guide

Disability Services Division · One DSD People, Access and Culture

1. What the tool is

The DSD HCBS Equity Policy Analysis Tool is a browser-based worksheet that guides an eleven-step equity analysis of a waiver amendment, state plan change, bulletin or manual page, rate or DWRS change, 245D standard, MnCHOICES change, lead agency process, self-direction policy, system change, Olmstead initiative, legislative proposal, bill or contract, consistent with the DHS Equity Policy and the State of Minnesota Equity Analysis Toolkit. It adds the federal-floor-versus-state-choice discipline, a step on lead agencies, providers and workforce, communication access by population, and a built-in walkthrough with a worked example.

This guide explains how to operate the tool: opening it, moving through the steps, filling in each kind of field, saving and reopening your work, producing the record, and what to do when something does not look right. It does not teach the method; the Facilitator Guide, the HCBS Companion and the Walkthrough do that.

2. Opening the tool

The tool is a single file, DSD_HCBS_Equity_Policy_Analysis_Tool.html. Save it anywhere on your computer or a shared drive and double-click it; it opens in your default browser (Edge, Chrome or Firefox). It needs no installation, no login and no internet connection. Nothing you type is sent anywhere.

Save DSD_HCBS_Equity_Policy_Analysis_Tool.html where you will find it again. The file never changes; it is the tool, not your analysis.

Double-click the file. If it opens in a program other than a browser, right-click it, choose Open with, and pick Edge or Chrome.

If you want it on your desktop or taskbar, bookmark the page in the browser.

If the page is blank or the steps do not appear, the browser may have blocked the file's script. Press F5 to reload, or open it in a different browser. On state laptops Edge is the safest choice.

3. The screen

The screen has a top bar and three columns. On a narrow window or a phone the columns stack; the steps become a scrolling row and a button in the top bar opens the Coach panel.

The top bar

ButtonWhat it does
New analysisClears every field and returns to Step 0. It asks you to confirm first. Save a draft before you use it if you want to keep the current work.
Open draft (.json)Opens a file picker so you can bring back an analysis you saved earlier.
Save draft (.json)Downloads a small file holding everything you have typed. See Section 6.
Load exampleFills every step with the worked scenario (a remote support service added to the DD and CADI waivers). It asks you to confirm because it replaces whatever is in the tool. Use New analysis afterwards to start your own.

The steps (left column)

Each step is a button; click any step at any time. The circle shows progress: empty means not started, gold means partly done, green means complete. "Complete" is judged by the quality check in the last step, not by whether every box has something in it. Below the list, a bar shows how many steps are complete, and once Step 0 is answered a gold box shows the review track the policy requires.

The worksheet (middle column)

The worksheet shows one step at a time. Each question has a short help line under it; many have an example in grey. At the bottom, Previous step and Next step move you through in order; on the last step, Next step returns to the start.

Coach and resources (right column)

The Coach tab changes with the step. It shows what the DHS Equity Policy or the toolkit says, questions to ask, what a strong answer and a weak answer look like, and common pitfalls. Read it before you type.

The Resources tab is the same on every step: what the policy requires, the HCBS instruments and where the analysis fits in each, the federal floor versus state choice, the DSD data to ask for early, the six policy objectives, the six ADSA goals, legal authorities, links into the One DSD program and to the official policy and toolkit, working definitions, and the privacy rule.

The Walkthrough tab also changes with the step. It gives plain-language instructions for the step, shows what the worked example says in every field of that step, and lists things to watch for. On the last step it adds two shorter scenarios. The button at the bottom loads the example into the tool.

5. Step 0 and the review track

Step 0 asks what you are analyzing, what kind of action it is, who is responsible, who will decide, and when. Then three questions determine the review track: how long the effects last, the highest approval level, and whether a formal analysis was already done. As soon as all three are answered, a box appears stating the track: a formal equity analysis required, or an equity scan likely sufficient. The same track appears in the left column so it stays visible on every step. Changing any of the three answers updates it at once.

The type list names HCBS instruments; choosing one shows a short note about where the equity analysis fits in that instrument's calendar. Below it, tick every service line the change touches. If the action is a waiver amendment, state plan change, rate change or system change, a field appears for the federal or system date (CMS submission, notice window, release date). If it is a legislative proposal or a bill, fields appear for the bill number and author, and the last step gains a button that copies an equity section for the bill analysis.

The affected communities grid

Step 2 is a table with one row per community or group. For each row choose the effect (Benefit, Burden, Both, Unknown or Not affected), the severity, and type how the group is affected, what evidence you have, and whether the group has been engaged. The left edge of the row turns green, red, purple or gold to match the effect, and the four boxes under the table count the rows. If any row is Unknown, a note reminds you to carry it into Step 3.

To add a group, click Add a group under the table and type the name in the new row.

To remove a row, click the × at the right end of the row. You cannot undo this; retype the row if you need it back.

To rename a group, click the name and edit it.

The grid is wider than the other steps; on a small screen scroll sideways within the table.

6. Saving and reopening your work

The tool automatically saves a draft in this browser on this device. Download a draft to keep a separate copy or move your work to another device. Open draft restores a downloaded copy. Drafts are not saved to the program server.

Click Save draft (.json) in the top bar, or the same button in the last step. A file named after your analysis and today's date goes to your Downloads folder, for example Remote-support-waiver-amendment-2026-10-03.json.

Move the file to the folder where your project lives, or a shared drive. It is small and plain text. Do not email it to anyone outside DHS; it holds your working notes.

To continue later, open the tool, click Open draft (.json), and choose the file. Everything returns as you left it, and the tool jumps to Step 0.

Save a new draft at the end of each sitting. Keep the old ones if you want a history; the date in the file name tells them apart.

If Open draft says "That file is not a draft from this tool", you chose a file that was not saved by this tool, or the file was edited and broken. Pick the correct .json file.

7. The last step: verdict, recommendations and quality check

Choose the verdict with the round options. Write the summary paragraph. Then add recommendations: each has a text box and three short fields for the owner (a role, not a name), the date, and the measure. Click Add a recommendation for more; click Remove to delete one. Tick the policy objectives and ADSA goals the action advances, and say how results will be communicated.

The quality check below is a list of statements that must be true before the record goes to a decision-maker. A green tick means done; a dash means not yet, with a link to the step where you fix it. The left column's progress circles use the same list. Aim for every line ticked; where you cannot, explain why in the summary.

8. Producing the record

Below the quality check, four buttons produce the output, and a preview of the Equity Analysis Record updates as you type. Fields you left empty show "Not recorded" in red so you can see them.

ButtonWhat happens
Print or save as PDFOpens the browser's print dialog with only the record on the page. Choose a printer, or choose Save as PDF as the destination to make a PDF for the approval package.
Copy record as textCopies the whole record to the clipboard as formatted text. Paste it into Word, an email or a memo; headings and tables come through.
Copy equity section for the bill analysisAppears only for legislative proposals and bills. Copies a compact section (position, communities benefited and burdened, federal floor and state choices, lead agency implementation, evidence, engagement, recommended amendments, fiscal notes) to paste into the standard bill analysis.
Save draft (.json)Same as the top bar button.

The record ends with a line stating that it supports, and does not replace, the official toolkit, required approvals, civil rights review, Tribal consultation and labor relations processes. Leave that line in.

9. Privacy and what to keep out

The tool is for analyzing a policy, not for recording a person's case. Keep case, medical, personnel, complaint and identifying details out of every field, including the team list and the engagement description. Describe people by role and community. Drafts are plain text files; treat them as working papers and store them where your unit stores working papers.

10. Accessibility

The tool works with a keyboard alone: Tab moves between controls, Space or Enter activates buttons and options, and arrow keys move within a group of round options. Every control has a visible focus outline. Headings, labels and tables are marked up for screen readers, and the step list announces the current step. Text can be enlarged with the browser's zoom (Ctrl and +) without losing any part of the screen. Colour is never the only signal: the grid's effect is also shown as a word, and the quality check uses a tick or a dash as well as colour. If any part is hard to use with assistive technology, report it through the One DSD Support page.

11. If something goes wrong

What you seeWhat to do
The page is blank or the steps are missingReload with F5, or open the file in Edge or Chrome.
The review track box has not appearedAnswer all three triage questions in Step 0; the box appears only when all are answered.
A step stays gold although I filled it inOpen the quality check in the last step and follow the link for the dashed item; a specific field is still empty.
My work disappearedCheck whether the browser restored its local draft. If it did not, open the most recent downloaded draft. Download a copy at the end of each session.
Copy did not workSome browsers block the clipboard on files opened from disk. Select the record preview with the mouse and copy it, or use Print or save as PDF instead.
Print shows the whole screen instead of the recordUse the Print or save as PDF button, not the browser's own print menu.
Links in Resources do not openThe One DSD program links need internet access. Everything else works offline.

12. Updating the tool

The lists in the tool (action types, default groups, routing paths, coach text, resources) are in a content block near the top of the file and can be edited in a text editor by the tool's owner. Update this guide when the tool changes. The Equity and Inclusion Operations Consultant leads the program and maintains the tool.
