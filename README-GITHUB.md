# One DSD People, Access and Culture

This private repository contains the application source from the October 31, 2026 Railway release, plus local public media, model assets, and reviewed-asset blobs. Install Git LFS before cloning, and run `git lfs pull` after cloning. The live database, environment secrets, research repository and separate handoff tools are not included. See db/standalone/README.md for database setup and config/railway-release-assets.json for the release asset inventory. Configure environment secrets and PAC_PUBLIC_ORIGIN for the new host, and adapt scripts/verify-clone-agent-pilot.mjs deliberately for the new service and domain without removing its checks. The full local handoff contains research and release tooling.
