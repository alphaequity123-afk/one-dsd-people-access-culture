## Closing: What this course covers (2:54–3:58)
**Visual:** A plain title card that reads "Tema Okun's Framework as a Reflective Tool." The narrator reads it aloud. The card changes to a simple list of four topics, each read aloud as it appears.

**{{NARRATOR}}:** Tema Okun's Framework as a Reflective Tool. This course takes the questions this team is asking seriously. You will learn where the framework came from, how its author has revised it since the original list, and what Okun has said it is and is not for. You will weigh its strengths and the published critiques, side by side. You will practice a reframing called Cultural Tensions in Public Service, which asks what happens when speed, standardization or control always wins. And you will practice using the lens on a process, such as how a timeline is set, without labeling a person. The framework is one lens in this pathway, beside others, and you will see where it connects to belonging, accessibility, leadership and well-being. As you go, keep this team's question in mind: how would you answer it?
