# Culture, Power, and Organizational Norms: video scripts

One script per module of the six-module path (courses `cpn-01` to `cpn-06` in `lib/content/courses/authored/gap-completion/`). Each is about 3.5 to 4 minutes and is written for the program's own cast.

- **Cast:** scripts use role tokens such as `{{SUPERVISOR}}`. The course practice cases use the same tokens, and `lib/content/courses/authored/gap-completion/cast.json` turns them into names. The names there now are placeholders; replace them with the program's characters and both the courses and these scripts line up.
- **Status:** scripts only. Nothing here is recorded or published.
- **Publishing:** record with the approved voices, add captions (VTT) and a transcript, then publish through the course-media volume (`lib/content/course-media.ts`) with the page path given in each script. No application release is needed for the video to appear.
