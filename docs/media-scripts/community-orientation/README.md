# Community courses and pages: orientation video script

One short orientation video for the Minnesota Communities pages and the Cultural Intelligence community courses, published on `/minnesota-communities`.

- **Cast:** speakers are identified by role and played by the recurring cast; `docs/media-scripts/CAST.md` lists which cast member and voice takes each role.
- **Status:** script only. Nothing is recorded or published.
- **Publishing:** record with the approved voices, add captions (VTT) and a transcript, then publish through the course-media volume (`lib/content/course-media.ts`) for `/minnesota-communities`.
