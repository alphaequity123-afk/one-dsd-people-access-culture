# Video script: The Minnesota Human Rights Act in Public Services and Program Design

- **Status:** Script only, written for the recurring cast (docs/media-scripts/CAST.md). Not recorded.
- **Publish on:** /courses/gc-mhra-public-services
- **Length:** about 3 minutes (about 415 spoken words)
- **Cast:** Discussion host 1 (C8, Host voice), Discussion host 2 (C4, Co-host voice), Supervisor (C6, Co-host voice), Case manager (C5, Host voice) (see docs/media-scripts/CAST.md)
- **Accessibility:** captions and a full transcript are required before publishing (docs/ACCESSIBILITY-STANDARD.md). On-screen text must also be spoken. Describe any visual that carries meaning.

## Scene 1: Three days before approval (0:00–0:30)
**Visual:** A shared workspace in a DSD office. The supervisor (C6) and the case manager (C5) sit side by side at a desk with a printed draft between them. The top line reads "Revised waiting list priority rule," which the hosts speak.
**Discussion host 1 (C8):** A revised waiting list rule goes to approval in three days. It gives priority to people whose caregiver will stop providing care within ninety days, shown by a signed letter from that caregiver. The case manager has been asked to read it one more time.

## Scene 2: Same rule for everyone (0:30–1:50)
**Visual:** The case manager (C5) taps a highlighted paragraph. The supervisor (C6) leans back, arms loosely crossed, listening.
**Case manager (C5):** The ninety-day standard makes sense to me. It's the letter I keep getting stuck on.
**Supervisor (C6):** The letter applies to everyone. That was the point. No one gets judged on how persuasive they are.
**Case manager (C5):** I know. But think about who writes that letter. Some caregivers on my caseload don't read or write English. Some are family members who won't sign anything that says they're stepping back, even when they are.
**Supervisor (C6):** So the rule is the same for everyone, and it still won't work the same for everyone.
**Case manager (C5):** That's what I'm worried about. And there's a second thing. People who use a screen reader can't fill out the upload page the way it's built.
**Supervisor (C6):** We can handle that through accommodation requests once it opens.
**Case manager (C5):** We could. Or we could fix it now, before anyone has to ask.
**Supervisor (C6):** Is this a legal problem or a design problem?
**Case manager (C5):** Honestly, I don't know. I know the Human Rights Act covers our programs. I don't know what it says about a rule like this one, where nobody meant to leave anyone out.
**Supervisor (C6):** I don't want to hold up a rule that's better than the one we have. But I also don't want to find out in a year that we built a barrier into it.

## Scene 3: The question on the table (1:50–2:20)
**Visual:** The supervisor (C6) writes a question on a sticky note and puts it on the draft. One host reads it: "Same rule. Same result?"
**Discussion host 2 (C4):** The question is a familiar one in program work. Is a rule that treats everyone the same enough? And what does Minnesota law expect of a public program before a rule goes out? Who should this team talk to before the approval meeting, and what should they bring to that conversation?

## Closing (2:20–3:00)
**Visual:** The course title appears on screen, followed by the four lesson titles, each read aloud.
**Discussion host 1 (C8):** This course looks at the Minnesota Human Rights Act from the program designer's seat. You'll see how the Act's public services provision reaches DHS and county programs, how to look for disparate treatment and unequal effects in a rule, how reasonable modification and undue hardship work in services, and how to test a rule before it goes out, with a record of your reasoning that others can review. Formal decisions about whether a practice violates the Act stay with the people and agencies responsible. Your part is to ask the questions while the draft can still change. We begin with lesson one: When a program is a public service under the Act.

## Transcript notes
A DSD supervisor and case manager review a waiting list rule that treats everyone the same but may not work the same for everyone. The course applies the Minnesota Human Rights Act's public services provisions to program design.
