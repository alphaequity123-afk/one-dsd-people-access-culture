# Workforce, civil rights, disability rights and accessibility: video scripts

One script per course for the twelve advanced and intermediate gap-completion courses in `lib/content/courses/authored/gap-completion/` that fill the program's thinnest outcome areas: equitable workforce practice, equity policy and civil rights, disability rights, and accessibility. Each is about 3 minutes and is written for the program's own cast.

- **Cast:** speakers are identified by role and played by the recurring cast; `docs/media-scripts/CAST.md` lists which cast member and voice takes each role. Four scripts are framed by the two discussion hosts, the paired Host and Co-host voices, instead of a single narrator, so the series does not open the same way every time.
- **Status:** scripts only. Nothing here is recorded or published.
- **Publishing:** record with the approved voices, add captions (VTT) and a transcript, then publish through the course-media volume (`lib/content/course-media.ts`) with the page path given in each script. No application release is needed for the video to appear.
