# Video script: Five Families

- **Status:** Script only, written for the recurring cast. Not recorded.
- **Publish on:** /courses/cn-navigators-and-system-change (Navigators and System Change)
- **Length:** about 2 minutes
- **Voices:** women in the cast use the female Host voice (`host1`), men use the male Co-host voice (`geffen`).
- **Accessibility:** captions and a full transcript are required before publishing (docs/ACCESSIBILITY-STANDARD.md). On-screen text must also be spoken.

**Cast:**

- **Narrator:** C3 (Host voice)
- **Navigator:** C1 (Co-host voice)
- **Program manager:** C2 (Host voice)
- **Newer colleague:** C7 (Co-host voice)
- **People served:** described or off camera, so no cast member is placed in a particular community.

**Scene 1. A hallway.**

NAVIGATOR: Five families this month read the renewal letter and thought their services were ending.

PROGRAM MANAGER: Thank you. Which part confused them? I'll log it and get back to you by the end of next week.

**Scene 2. The program manager and the newer colleague at a whiteboard.**

NEWER COLLEAGUE: Let's rewrite every letter we send.

PROGRAM MANAGER: Let's start with this one. A plain summary at the top. We try it with ten families, through the navigator, and see if they understand it.

**Scene 3. Two months later.**

PROGRAM MANAGER: (reading) On-time renewals went up in the test group. Scheduling didn't change, but it's a small group. We'll keep watching.

NARRATOR: And the announcement credits the navigator, and the organization they work for.

NARRATOR: Listen for patterns. Test small. Measure honestly. Share the credit.
